# 🌱 My First Cellular Automata

A playful, interactive introduction to cellular automata—learn step-by-step, then experiment with your own rules in a glowing sandbox.

---

## ✨ What is this?

**My First Cellular Automata** is a kid-friendly, visual experience designed to teach how simple rules can create complex, evolving patterns.

Instead of throwing you into a simulation, the app **guides you step-by-step**:

* 🟪 Learn what a “cell” is
* 🟩 Discover how neighbors work
* ✨ See rules come to life
* 🎮 Then jump into a sandbox to experiment freely

---

## 🎮 Features

* 📖 **Story Mode**
  A guided, interactive tutorial that builds intuition from scratch

* 🎨 **Sandbox Mode**
  Create your own patterns and rules

* ⚡ **Real-time simulation**
  Watch patterns evolve instantly

* 🧠 **Custom rule system**
  Define when cells are born or survive

* 📱 **Touch-friendly design**
  Built for both desktop and mobile play

---

## 🧩 How it works

Each cell follows simple rules:

* It looks at its neighbors
* Counts how many are ON
* Decides whether to turn ON or stay ON

Even with simple rules, the system creates **emergent behavior**—patterns that feel alive.
